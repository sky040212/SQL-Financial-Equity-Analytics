# Financial Equity Analytics Pipeline (SQLite & Python)

## 1. Project Overview
This end-to-end data engineering and financial analysis pipeline automates the ingestion, transformation, storage, and visualization of corporate equity data. Built for financial analysts, the system handles multi-source financial ingestion, structures data into a robust relational database, computes key performance ratios, and generates automated presentation-ready PDF/Excel reporting and visualizations.

### Core System Components:
1. **Data Ingestion & Extraction Layer**: Connects to financial data sources, reads raw balance sheets, income statements, and daily historical stock prices, performing schema enforcement and initial deduplication.
2. **Transform & Model Layer**: Normalizes financial metrics, computes key ratios (Liquidity, Profitability, Leverage, Valuation), and prepares clean tabular metrics for persistence.
3. **Storage Layer (SQLite)**: Operates a transactional relational database holding normalized corporate profiles, daily stock histories, and periodic financial statements.
4. **Analysis & Visual Generation Engine**: Executes SQL aggregation queries to build analytical dataframes, producing visualization plots and interactive Excel deliverables.

## 3. Database Schema Design (SQLite)
The database follows a 3NF normalized design to ensure integrity, prevent data anomalies, and optimize analytical queries.

### `companies` Table
Stores metadata about the corporations tracked by the system.
*   `ticker` (VARCHAR PRIMARY KEY): Unique stock ticker symbol (e.g., AAPL, MSFT).
*   `company_name` (VARCHAR NOT NULL): Full legal name of the entity.
*   `sector` (VARCHAR): Economic sector classification (e.g., Technology, Healthcare).
*   `industry` (VARCHAR): Industry subgroup.

### `daily_prices` Table
Tracks daily stock price movements and volume.
*   `price_id` (INTEGER PRIMARY KEY AUTOINCREMENT): Unique surrogate key.
*   `ticker` (VARCHAR FOREIGN KEY references `companies(ticker)`): Associated stock ticker.
*   `date` (DATE NOT NULL): Trading calendar date.
*   `open` (DECIMAL):
*   `high` (DECIMAL):
*   `low` (DECIMAL):
*   `close` (DECIMAL): Closing share price adjusted for splits.
*   `volume` (BIGINT): Total traded shares during the session.

### `financials` Table
Contains historical periodic financial statement metrics.
*   `financial_id` (INTEGER PRIMARY KEY AUTOINCREMENT): Unique surrogate key.
*   `ticker` (VARCHAR FOREIGN KEY references `companies(ticker)`): Associated stock ticker.
*   `fiscal_year` (INTEGER NOT NULL): Financial reporting year.
*   `period` (VARCHAR NOT NULL): Period code (e.g., 'FY', 'Q1', 'Q2').
*   `revenue` (DECIMAL): Top-line sales revenue.
*   `net_income` (DECIMAL): Bottom-line net profit.
*   `total_assets` (DECIMAL): Total assets on balance sheet.
*   `total_liabilities` (DECIMAL): Total debts and obligations.
*   `operating_cash_flow` (DECIMAL): Cash generated by core business operations.

## 4. Financial Analyst Use Cases
*   **Automated Equity Research**: Automatically extracts financial statements, calculates DuPont return metrics (ROE, ROA), and generates performance reports without manual data entry from filings.
*   **Risk Management & Credit Profiling**: Evaluates solvency ratios (Debt-to-Equity, Interest Coverage) and liquidity indicators (Current Ratio) over time to flag companies at risk of distress.
*   **Relative Valuation Comparison**: Joins daily market prices with latest financial statement data to calculate dynamic valuation multiples (Trailing P/E, EV/Sales, Price-to-Book) across peer universes.
